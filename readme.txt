# Probeats — Maquette UI/UX complète (Desktop + Mobile)

Ce dépôt contient l’ensemble du projet **Probeats**, une maquette UI/UX réalisée en Figma comprenant :
- 5 pages **desktop**
- 5 pages **mobile**
- Un **design system complet** (couleurs, typographies, composants, grille)
- Le **flow utilisateur** (navigation complète entre les pages)

##  Design System

Le design system utilisé dans le projet inclut :

###  Couleurs
- White — #FFFFFF  
- Background — #F4F4F4  
- Panel — #D9D9D9  
- Dark — #202020  
- Grey — #777777  
- Accent — #00A6A6  

###  Typographie
**Barlow**  
- H1 — 34px  
- H2 — 26px  
- Body — 18px  

###  Composants
- Boutons (CTA, secondaires)  
- Champs de formulaire  
- Icônes (menu, navigation)  
- Cartes produits  

###  Grille
- Desktop : **12 colonnes**  
- Mobile : **4 colonnes**

Le fichier du design system est disponible dans le dépôt :  
`00-Design-system.svg`

##  Flow utilisateur

Le flow couvre :
- Navigation complète entre les 5 pages  
- Parcours d’achat (Accueil → Produit → Commande)  
- Accès aux pages d’information (À propos, Assistance)  
- Version mobile optimisée
